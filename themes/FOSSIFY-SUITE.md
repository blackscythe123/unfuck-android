# The Fossify Open-Source App Suite

OEM system utilities (Dialer, Gallery, Messages, Calculator, Voice Recorder) frequently include
unwanted cloud sync popups, analytics trackers, or commercial upsells.

The **Fossify** suite consists of 100% open-source, offline, ad-free successors to the renowned
Simple Mobile Tools series.

---

## Recommended Fossify Replacements

| OEM App | Fossify Replacement | Key Benefits |
|---|---|---|
| **Stock Gallery** | **Fossify Gallery** | No cloud sync popups, ultra-fast RAW/video preview, built-in photo editor. |
| **Stock SMS/Messages** | **Fossify Messages** | Clean Material You design, instant search, no promotional spam categorization. |
| **Stock Phone / Dialer** | **Fossify Phone** | Call blocking, speed dial, dual SIM support, 100% offline. |
| **Stock Calendar** | **Fossify Calendar** | Syncs via CalDAV or local offline calendars without Google/OEM account requirement. |
| **Stock Calculator** | **Fossify Calculator** | Fast, simple, offline calculator with history and unit conversion. |
| **Stock Voice Recorder** | **Fossify Voice Recorder** | High-quality audio recording with zero telemetry or background network access. |
